Core Features

核心功能

四大实用工具，快捷键一键开关，最小化托盘后后台同样有效

🔨

自动铲子 F8

长按鼠标左键建造工事、长按右键刨除工事。按住约 3 秒自动进入建造/刨除状态，无需一直按着，松开或移动鼠标即停止。黑奴的福音，龟壳队的帮手。

🚀

极速抢车 F9

仅在 Squad 位于前台时，自动循环粘贴建队命令，快速抢占小队位。支持自定义小队名称与发送间隔（超快 10ms / 快速 50ms / 标准 100ms）。今晚我在秋名山等你。

🏃

自动奔跑 F10

适用于无限体力服务器，开启后自动按住 W + Shift 持续奔跑，解放双手。按下任意键或切出 Squad 窗口时自动停止，安全省心。

🗺️

地图工具

支持 RAAS 地图猜点与迫击炮等远程火力坐标计算。启动后自动扫描 Squad 日志中的最新地图与 Layer，首次打开即定位到对应地图页面。

More

更多亮点

从计算器到猜点，把每一个细节都安排明白

🎯

迫击炮计算

带高度差计算、置顶标识与常用点位热力图，还能结合 OCR 同步游戏内地图。

🀄

RAAS 猜点

出门慢输一半，跑错路输全部。猜点模块帮你快速找到本局点位刷新路线。

🌐

网络代理

设置页可配置 HTTP / SOCKS5 代理，仅作用于地图工具的远程访问。

🌗

深浅色主题

主界面基于 Avalonia 与 SukiUI，支持浅色 / 深色主题一键切换。
