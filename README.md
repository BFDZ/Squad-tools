# Squad小帮手

一个 Squad 游戏小工具：本地运行、无需登录，体积小、启动迅速。

## 运行说明

- 系统要求：Windows 10/11，需已安装 [.NET](https://dotnet.microsoft.com/en-us/download)
- 请以与游戏相同的权限运行本工具（游戏以管理员身份运行时，本工具也需管理员身份运行）
- 程序启动后可最小化到托盘，快捷键在后台同样有效
- 已知小问题：因为快捷键和载具乘员位快捷键冲突，必须先启动进入游戏，然后才能打开小帮手程序，否则小帮手的功能无法开启

## 功能与快捷键

### 1. 自动铲子（快捷键 F8）

长按左键建造工事，长按右键刨除工事。

- 按 `F8` 或点击按钮开启/关闭
- 开启后，按住鼠标左键或右键约 3 秒即自动进入建造/刨除状态，无需一直按着
- 松开按键或移动鼠标即停止

### 2. 极速抢车（快捷键 F9）

仅在 Squad 位于前台时，自动循环粘贴建队命令（`createsquad 小队名 1`），快速抢占小队位。

- 填写小队名称，选择发送间隔（超快 10ms / 快速 50ms / 标准 100ms）
- 按 `F9` 或点击按钮开启/关闭

### 3. 自动奔跑（快捷键 F10）

适用于无限体力的服务器，开启后自动按住 W + Shift 持续奔跑。

- 按 `F10` 或点击按钮开启/关闭
- 切回 Squad 窗口后自动开始奔跑
- 按下任意键盘按键或切出 Squad 窗口时自动停止
